How verification works
  1. The issuer computes the deterministic SHA-256 hash of the canonical certificate data off-chain.
  2. The hash is recorded on-chain via issueCertificate() with an immutable timestamp.
  3. Scanning the QR code extracts the certificate hash and verifies it against the smart contract.
  4. For document certificates, upload the original PDF to check its bytes against the blockchain. A QR lookup checks registration and revocation; accompanying metadata is not independently verified.
